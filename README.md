WiFi Sharing Tool
A lightweight command-line utility built with Python to quickly share files or host a local server over your Wi-Fi network using standard built-in libraries.

Overview
This tool uses Python's built-in modules to start a local HTTP server, allowing you to easily transfer files across devices connected to the same network without needing any external packages.

Features
Zero external dependencies (uses Python standard libraries only)

Quick file sharing over a local network

Simple command-line interface

Prerequisites
Python 3.x installed on your system.

Installation
Clone the repository to your local machine:

Bash
git clone https://github.https://github.com/hridyanshjoshi780-svg/wifi-sharing.git
cd wifi-sharing
Usage
Run the script from your terminal using Python:

Bash
python filename.py
(Note: Replace filename.py with the actual name of the script in your repository.)

Once running, the terminal will provide a local URL. Open that URL in any browser on your network to access and transfer files easily.
